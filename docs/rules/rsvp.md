# 快速字母流规则与取证

日期: 2026-11-10. 状态: 实现, 尚未完成全部来源一致性验收. 用户要求跳过后续测试并提交、合并和推送.

## 来源与证据

A07 部署脚本确认默认 150ms/15 字/2 红色, 显式初级 200ms/12/1、中级 150ms/15/2、高级 80ms/20/3. 红色位置不在前两位; 六个唯一选项含全部不同红色字母, 选中任意一个即正确, 400ms 后展示答案, 手动继续. 本站增加结束并保存累计正确率. 源脚本缺少解锁写入, 本站采用页面说明的一轮正确解锁下一预设; 用户选择跳过测试, 此差异未完成一致性验收.

部署脚本与公开源码仅用于核对规则, 不代表实际运行验收, 未搬用实现或素材. 入口映射见 [冻结目录](baseline.md), 许可见 [素材清单](assets.md).

## 本地实现快照

以下为当前模块配置, 未经上文证据确认的数值保留待证状态.

### 快速字母流 (letters)

- 规则版本: 3. 页面隐藏: invalidate. 输入: pointer, touch, keyboard.
- 主成绩: %, 越大越好, 0..100. 有效结算后保存.
- 操作: 观察字母流, 在六个选项中选择任意一个出现过的红色字母. 每轮后可继续或保存本次正确率. 初级和中级各答对一轮可解锁下一预设.

| 预设 | ID | 设置 | 解锁 |
| --- | --- | --- | --- |
| 默认 | `default` | `{"intervalMs":150,"count":15,"targets":2}` | 自由 |
| 初级 | `easy` | `{"intervalMs":200,"count":12,"targets":1}` | 自由 |
| 中级 | `medium` | `{"intervalMs":150,"count":15,"targets":2}` | rsvp:medium |
| 高级 | `hard` | `{"intervalMs":80,"count":20,"targets":3}` | rsvp:hard |
| 自定义 | `custom` | `{"intervalMs":150,"count":15,"targets":2}` | rsvp:medium |

- 字段 `intervalMs`: 每字呈现, {"key":"intervalMs","label":"每字呈现","type":"number","min":150,"minByUnlock":[{"key":"rsvp:medium","min":100},{"key":"rsvp:hard","min":80}],"max":250,"step":10,"unit":"ms"}.

- 字段 `targets`: 红色字母数量, {"key":"targets","label":"红色字母数量","type":"number","min":1,"max":2,"maxByUnlock":[{"key":"rsvp:hard","max":3}],"step":1}.
