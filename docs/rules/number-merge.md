# 数字合并

- 来源: ToolOnline 2048, 2026-11-10 网页正文. 正文描述 4×4 棋盘, 相同数字合并, 填满且无法合并结束, 支持滑动、方向键和 WASD.
- 本站实现: 开局两个方块, 有效移动后随机生成 2 或 4; 相同方块每次移动最多合并一次, 得分为合并得到的数字之和. 达到 2048 后继续, 无法移动时结算. 鼠标按钮、触屏滑动及键盘可操作.
- 待证: 来源的生成概率、无效移动、合并计分、达到 2048 后行为和结束流程尚未运行核验. 本站上述行为是独立实现, 不能视为来源运行对齐. 本站页面隐藏作废; 设置、输入与规则版本分组由记录层处理.
- 素材: 程序生成数字和界面, 无第三方游戏素材.
