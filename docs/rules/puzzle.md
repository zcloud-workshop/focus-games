# 行列拼图

- 来源: ToolOnline 拼图达人, 2026-11-10 实施计划记录参考页面. 本次网页读取不可用; 计划描述行列各 3-8、长滑连续交换、按住预览及本机自选图片.
- 本站实现: 打乱整行和整列, 拖动跨越相邻行列逐次交换, 首次有效交换开始计时. 原创默认图形和本机选择的图片绘制到 canvas; 图片使用 createImageBitmap 解码并居中裁剪, 不上传, 使用图片 SHA-256 作为本机成绩分组标识. 按住按钮预览, 更换图片重开, 页面隐藏作废.
- 待证: 来源行列预设、步数、计时及边界反馈未运行核验. 本站实现是独立规则, 不宣称来源运行对齐.
- 素材: 默认图形由程序绘制; 自选图片由用户提供并留在浏览器本机.
