# 物品短期回忆

来源 C15: /zh/games/free-short-term-memory-test

2026-11-10 通过浏览器实际操作: 展示 12 个词, 点击准备后出现 12 个可任意顺序填写的输入框; 至少一项非空时可提交. 测试中输入两个相同的正确词、一个错误词, 结果计为 1/12; 结算后重新测试显示新的 12 项. 参考页面提交后要求选择年龄段和性别才能查看结果, 本站不收集这些信息, 也不提供缺乏本站数据依据的常模.

本站使用原创线描与中文词表, 12 项不重复, 按准备按钮后隐藏, 各项最多计一次, 别名见代码词表. 主成绩为正确的不同物品数, 范围 0-12, 越高越好; 设置、模式、输入与规则版本分组. 切页作废. 输入不设时限, 结束时记录用时. 固定版本源码观察 (非运行核验): 回忆阶段开始计时, 输入去空格后允许物品名称和答案互相包含; 本站记录回忆阶段秒数并支持同样的包含关系及原创词表别名. 短输入可能匹配多个物品, 这是参考站的宽松规则. 源码: https://github.com/loethen/freefocusgames/tree/88336ed4e2f101998c2cb53794593a934390db9d.

参考的全部页面退出、中断与重开边界尚未完整核验; 本站已在独立端口实测别名、重复答案、错误项、结算及本机保存.
