# 位置记忆

来源 A10 /number-memory/; T01 /number-sequence-memory.

本站提供数字/字母位置记忆和首击隐藏两种模式. 前者定时隐藏后按序选择; 后者从 4 个起, 点击 1 后隐藏其余数字, 每关增加一个并有三次失误机会. 本站暂定 5×5 空间、每次失误重新生成该关、全盘完成为结束, 来源 A 部署脚本显示数字位置预设为 3×3/2500ms、4×4/2000ms、5×5/1500ms, 错误仅提示 300ms 并继续, 完成得格数分; 完成前两级分别解锁中级、高级和字母模式. 自定义尺寸与时长随进度开放, 字母上限为 26. T01 参数和生命细节尚未运行核实, 不视为完全对齐. 旧整串数字成绩不能混入这些成绩. 浏览器验收待做.

A 信息为源码观察, 非参考站完整流程验收. 本轮按用户要求跳过测试和交互验收.
