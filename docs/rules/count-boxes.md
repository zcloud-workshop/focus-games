# 数箱子

- 来源: FreeFocusGames 数箱子, 2026-11-10 网页正文. 页面描述短暂观察三维立方体, 消失后输入数量并逐关提高难度; 页面游戏区为加载占位.
- 来源源码证据: [GameComponent.tsx](https://github.com/loethen/freefocusgames/blob/88336ed4e2f101998c2cb53794593a934390db9d/app/%5Blocale%5D/(main)/games/counting-boxes/components/GameComponent.tsx) 使用六关, 答对或答错均继续, 结算正确率; 各关目标数量分别为 3-4、4-6、5-7、7-9、3-4、20-23, 静止呈现区间分别为 800-1000、700-800、600-800、600-800、250-300、300-400 毫秒, 第 2-4 关可选 3 秒飞行动画. 此为源码阅读, 未验证线上实际运行.
- 本站实现: 按上述六关数量与时序生成, 随机使用飞行或静止呈现, 错对均显示答案后继续, 保存正确率与逐关结果. 一排分离且受支撑的原创箱堆每层均可见, 由同一模型计算箱数, 避免不同数量产生相同画面. 两次帧回调时间差保存在试次数据; 页面隐藏作废.
- 待证: 线上实际版本与随机模式、反馈时序和动画一致性未运行核验; 原站的三维网格与图案由本站不同的单排可辨识图形替代, 不宣称完整对齐.
- 素材: 程序生成 SVG, 无第三方素材.
