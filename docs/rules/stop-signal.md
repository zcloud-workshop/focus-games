# 停止信号

来源: A17 /stop-signal/.

2026-11-10 证据: 网页正文显示左右箭头及延迟出现红框, 停止比例 25%, 显示延迟范围 150-400ms. Chrome 实际检查锁定提示: 初级抑制成功率达到 80% 解锁中级, 中级达到 75% 解锁高级. 初级运行开始后仅观察到部分试次, 结束前 Mac 锁屏; 自定义尚未解锁.

本站以 150-400ms 范围内随机停止延迟和固定响应窗口计算抑制正确率, 按观察到的门槛解锁. 三档等待参数暂时相同, 默认试次数、分布、响应窗和自定义范围为本站暂定, 非已证实的参考流程.

待证: 参考站完整的开始、正确、错误或超时、结束和重开流程, 各预设、自定义范围、实际输入时机、解锁、统计与排名资格. 本模块为本地基础实现, 未完成参考规则对齐和浏览器验收.
