# 停止信号

来源: A17 /stop-signal/.

2026-11-10 证据: 网页正文显示左右箭头及延迟出现红框, 停止比例 25%, 显示延迟范围 150-400ms. Chrome 实际检查锁定提示: 初级抑制成功率达到 80% 解锁中级, 中级达到 75% 解锁高级. 初级运行开始后仅观察到部分试次, 结束前 Mac 锁屏; 自定义尚未解锁.

当前部署页面内嵌脚本只读观察: 40 试次, 响应窗 1200ms; 显式选择初/中/高级的停止比例为 20%/25%/30%, 延迟分别 250-500/150-400/50-250ms, 超时后间隔 500ms, 响应后反馈 400ms, 无自适应. 自定义初始比例 10-30%、步长 5%, 最短延迟 250-500ms、步长 50ms, 最长为最短加 250ms. 初始变量却为 25%/150-400ms 且显示初级, 与显式点选初级不同. 这是源码观察, 并非运行验收.

本站按显式选择预设和观察到的门槛实现; 自定义解锁后的动态字段范围与源站实际运行仍待核验.
