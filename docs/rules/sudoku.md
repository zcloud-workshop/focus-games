- 本站实现: 独立生成并变换三组题面, 解题器验证唯一解. 简单可用显性单数解完, 普通需要隐性单数且可用两种单数解完, 困难不能仅用这两种单数解完. 两种模式分开记录; 笔记模式提供候选数、提示、擦除及 N 键切换. 已知数字不可改, 错误三次结束且不计正式成绩, 完成记录用时、错误和提示; 有无提示分别分组. 页面隐藏作废.
- 待证: 两来源的难度生成、计时起点、错误、提示代价、候选数细节和结束流程尚未运行核验. 本站分级和提示处理是独立决定, 不宣称来源运行对齐.
- 素材: 程序生成数字和棋盘, 无第三方素材.
