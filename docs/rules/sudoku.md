# 数独

- 来源: ToolOnline 数独, FreeFocusGames 专注数独, 2026-11-10 页面正文与计划. 来源 B 描述 9×9、三次错误和按解题技巧分级; 来源 C 的笔记、擦除、提示等列于实施计划, 本次未运行核验.
- 来源 C 源码证据: [FocusSudokuClient.tsx](https://github.com/loethen/freefocusgames/blob/88336ed4e2f101998c2cb53794593a934390db9d/app/%5Blocale%5D/(main)/games/focus-sudoku/components/FocusSudokuClient.tsx) 显示错误次数但没有三错终止分支; 选中空格提示会加一次错误, 未选中空格则随机提示而不加错误, 支持暂停与方向键. [生成器](https://github.com/loethen/freefocusgames/blob/88336ed4e2f101998c2cb53794593a934390db9d/lib/sudoku.ts) 以唯一解为约束, 简单/中等/困难目标挖空 30/40/50 格. 这些是源码观察, 未验证线上运行.
- 本站实现: 独立生成并变换三组唯一解题面, 简单可用显性单数解完, 普通需隐性单数, 困难不能仅用这两种单数解完. 基础模式错误三次结束且不计正式成绩; 笔记模式错误后继续, 支持候选数、提示、擦除、N 键、方向键与暂停, 提示的错误数规则参照上述源码. 完成记录用时、错误和提示, 有无提示分别分组. 页面隐藏作废.
- 待证: 两来源线上计时起点、错误、提示、候选数和结束流程尚未运行核验. 本站按技巧分级与来源 C 挖空数目标不同, 不宣称完整对齐.
- 素材: 程序生成数字和棋盘, 无第三方素材.
