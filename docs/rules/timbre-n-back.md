# 音色回溯

来源 A28 /timbre-n-back/. 本站提供四种不同频谱的合成音色试听, 基音相同, 不用高低音冒充音色变化. 包含 1-Back 慢/快与 2-Back, 自定义回溯和间隔, 判断相同/不同并单列漏答.

这些是原创合成声音, 不声称真实乐器采样. 部署脚本显示预设为 1/2500ms、1/1500ms、2/1500ms, 每局共 20 次刺激, 前 N 项不作答, 只用已答题作正确率分母; 自定义 N=1-3、间隔 1000-3000ms. 本站音色频谱和时长使用自有合成, 并非来源音包; 参考站完整流程、试听可辨识度、真实设备声音与退出清理仍待运行验收, 不标称完全对齐. 本轮按用户要求跳过测试和交互验收.
