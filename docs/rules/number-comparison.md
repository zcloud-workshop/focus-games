# 较大数字

来源: C17 /zh/games/larger-number.

2026-11-10 证据: 计划记载 30 秒内选择较大数字.

来源 C 源码观察 (固定提交 [88336ed](https://github.com/loethen/freefocusgames/tree/88336ed4e2f101998c2cb53794593a934390db9d)): 初始数字 10-99, 差至少 2, 30 秒统计正确数; 初始目标为至少 25 次、90% 正确率, 成功后下轮目标次数增加 3、最小差缩至至少 1, 失败时允许降低难度. 此为源码观察, 非运行验收.

本站按等级调整最小差和目标, 达标解锁下一级并在下次进入时默认选择, 已解锁等级可手动降低. 本地以等级隔离成绩. 参考站的跨局 UI 与排名资格仍待运行核验.

待证: 参考站完整的开始、正确、错误或超时、结束和重开流程, 各预设、自定义范围、实际输入时机、解锁、统计与排名资格. 本模块为本地基础实现, 未完成参考规则对齐和浏览器验收.
