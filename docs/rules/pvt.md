# 持续警觉

来源: C06 /zh/games/psychomotor-vigilance-test.

2026-11-10 证据: 计划记载 3/10 分钟、1-4/2-10 秒等待、355/500ms 走神阈值及 100ms 抢按阈值; 本次页面读取不可用.

来源 C 源码观察 (固定提交 [88336ed](https://github.com/loethen/freefocusgames/tree/88336ed4e2f101998c2cb53794593a934390db9d)): 两档分别为 3/10 分钟, 等待 1-4/2-10 秒, 走神阈值以 >=355/>=500ms 判断, 小于 100ms 或等待时输入算抢按; 30 秒未响应记为 30000ms 的走神, 反馈 1 秒. 前后 10% 样本数四舍五入且至少一个, 结果主值为中位数. 此为源码观察, 不是运行验收.

本站实现上述统计并保存各次反应及响应速度. 没有有效样本时不保存成绩; 运行、边界及页面隐藏行为仍待验收.
