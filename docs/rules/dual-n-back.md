# 双通道回溯

来源 A09 /dual-n-back/; C02 /zh/games/dual-n-back; C13 /zh/games/mahjong-dual-n-back.

本站分别提供位置/音调、位置/字母语音、图形身份/声音三个模式及约 30 秒不计分练习. 两通道各自生成目标并记录命中、漏报、误报、正确拒绝; 图形模式比较图形身份而非位置. 暂定 35% 目标率、20 个正式试次和 2500ms 间隔. 字母只使用设备上的本地英文语音, 无可用声音或播放失败时中止并提示, 不调用远程语音; 牌面与音调为本站原创. 帧对齐呈现并记录每次实际呈现时间、时长及两通道响应. 排名资格按 C02 页面说明仅对至少 2-Back、20 试次、80% 正确的正式模式标记; 推荐升级阈值不自动升级.

预设、音频可听性、语音语言和时序、各来源完整开始/错误/结束/重开、教程引导及自动升级尚未运行核验, 本站参数为暂定, 不标称对齐. 音频不可用时明确提示; 退出停止声音.
