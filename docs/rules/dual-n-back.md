# 双通道回溯

来源 A09 /dual-n-back/; C02 /zh/games/dual-n-back; C13 /zh/games/mahjong-dual-n-back.

固定版本源码观察, 非运行验收: https://github.com/loethen/freefocusgames/tree/88336ed4e2f101998c2cb53794593a934390db9d. C02 默认 1-Back、总刺激 20、间隔 3000ms, N 值 1-10、界面总刺激 10-50 步长 5、间隔 1000-5000ms 步长 250ms. 预热计入总刺激数; 综合正确率按每个可评分试次中所有启用通道均正确计算, 而不是两通道判断的平均值. 来源选择单位置、单声音或双通道; 每局选 8 个不同字母. 源码将 20% 作为强制匹配概率, 非强制随机也可能偶然匹配. 页面规则中的双通道、N 至少 2、总刺激至少 20、综合正确率至少 80% 用于排名资格, 不是自动升级规则. C13 默认 2-Back、20 个总刺激和 3000ms 间隔, 视觉比较牌面身份.

本站分别提供位置/音调、位置/字母语音、位置单通道、字母声音单通道、牌面身份/声音以及约 30 秒不计分教程. 教程依次引导位置、声音和同时匹配并给出反馈; 与参考的五步教程并不完全一致. 两通道分别保存命中、漏报、误报、正确拒绝, 帧对齐并记录实际呈现时长与响应. 源码观察到的 C02 总刺激、默认节奏、八个原创选用字母及逐题综合口径已纳入; A09 的参数仍暂定. C13 使用原创图形牌面与合成音, 声音集合及计分细节未完全复现.

英文语音只使用设备上的本地 voice, 无可用声音、播报失败或未在窗口内结束时中止且不计分; 真实设备可听性、各来源完整开始/错误/结束/重开和教程仍需运行验收. 参考声音与牌面素材未复制.
