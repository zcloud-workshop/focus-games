# 心理旋转

- 来源: 专注力训练心理旋转, 2026-11-10 网页正文. 初始页面显示 3×3、3×3 复杂、4×4、自定义、15 题与网格大小输入.
- 运行观察: 初始界面锁定中级和高级. 点击自定义时提示需在初级达到 80% 正确率; 点击高级时提示需在中级达到 85%. 仅核对锁定提示, 未完成训练验证解锁生效或重开.
- 本站实现: 选择能旋转重合的图形, 其他三项为镜像的不同旋转. 按提示为中级及自定义设置初级 80% 门槛, 为高级设置中级 85% 门槛. 随机生成相连且具手性的方块图形, 自定义题数 5-40, 默认 15 题, 记录正确率. 页面隐藏作废.
- 待证: 来源选项生成、参数范围、反馈、成绩和实际解锁流程未核验. 本站自定义参数是独立决定, 不宣称来源运行对齐. 按用户要求跳过本轮测试和浏览器验收.
- 素材: 程序生成 SVG, 无第三方素材.
