# 听觉注意力

来源 A27 /auditory-attention/. 页面列出 1-Back 慢速、1-Back 快速、2-Back 与自定义, 自定义初始间隔 2500ms. 本站合成四个音调, 对每次有效试次分别判断相同/不同, 漏答单独计数; 训练结束和退出关闭声音.
