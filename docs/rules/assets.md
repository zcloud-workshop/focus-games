# 素材与许可清单

日期: 2026-11-10. 本批不下载或复制三个参考站的美术、录音、题库、品牌和长篇文案. 界面使用本站已有 SVG 图标、CSS 和系统字体; 训练素材随各模块按需加载, 不使用第三方运行时 CDN.

| 用途 | 实现与来源 | 许可及署名 | 体积与加载 |
| --- | --- | --- | --- |
| 图片回溯 | 模块内自绘图形 | 本站原创, 使用仓库许可 | 随 nback 模块 |
| 字母声音 | 浏览器本地英文 voice, 严格 localService | 依设备已有本地语音, 不下载或再分发语音资源; 不可用时提示且不记分 | 无额外音频文件 |
| 双通道牌面 | 自绘 SVG 牌面身份 | 本站原创, 使用仓库许可 | 随听觉模块 |
| 四种音色 | Web Audio 同基音不同谐波/波形组合 | 本站程序合成, 不使用乐器采样 | 随音频引擎 |
| 物品词表与图片 | 独立中文词表、别名、自绘线稿 SVG | 本站原创, 使用仓库许可 | 随 object-recall 模块 |
| 动物配对 | 可辨识的动物 SVG 与中文名 | 本站原创, 使用仓库许可 | 随 memory-match 模块 |
| 默认拼图 | canvas 绘制独立几何场景 | 本站原创, 使用仓库许可; 用户图片仅本机解码 | 随 puzzle 模块 |
| 起步灯 | 独立圆灯图形 | 本站原创, 不使用赛事标志 | 随 reaction 模块 |
| 秒针与提醒 | Web Audio 短提示音 | 本站程序合成 | 随 audio/time/pomodoro 模块 |
| 竹知了 | 自绘 SVG 竹筒与绳, 独立手势/惯性和合成声音 | 不使用参考项目代码、录音或小蝉美术 | 随 bamboo-cicada 模块 |
| 其他图形与题目 | 程序生成, 数独/火柴棒经纯规则验证 | 本站独立实现, 不搬用商业测试题库 | 随所属模块 |

来源 C 页面将竹知了称作开源适配, 但其所链项目当前 [LICENSE](https://github.com/imsai-sh/zhuzhiliao/blob/main/LICENSE) 为 Zhuzhiliao Source-Available License, 明确没有授予再分发与第三方可访问部署的权利. 本项目因此独立实现传统玩具的交互机制, 不复用其受限内容, 也不将来源页面的“开源”说法作为授权依据.

`public/_headers` 保持原 CSP. 自选拼图图片以 createImageBitmap 解码并绘制到 canvas, 不创建远程 URL 或对象 URL, 不需要开放 blob:. 音频在用户操作后启用, 退出时清理, 动作权限仅在用户主动启用时请求.

构建验证的入口19.03 KB gzip, 低于25 KB建议预算. 模块 gzip 的实际测量以构建输出和验收记录为准, 后续新增素材必须重新测量. 真实声音可辨性、本地英文 voice 的设备覆盖和手机动作感应仍须真机验收.
