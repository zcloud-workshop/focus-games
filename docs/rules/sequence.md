# 序列记忆

来源: A11 /sequence-memory/; T02 /sequence-memory; C09 /zh/games/sequence-memory-test; C12 /zh/games/frog-memory-leap.

依据项目对照计划, 方格模式提供 3×3 慢速、快速和 4×4, 按钮序列单列, 正序/倒序挑战从 3 步开始, 练习不计分. 路径模式以原创标记在圆形位置间连续移动, 回答按落点顺序. 观察期间不接受输入; 每轮续加一步, 错误结束, 记录最长完整长度. 自定义网格 2-5 和显示 150-1500ms、路径初始位置、动画和具体时间是本站暂定值, 不是来源实测结论.

尚未运行核验各入口成功、错误和重开全流程; 预设时长、生命、路径起点、练习设置和解锁均待证. 本站浏览器、成绩分组及触控验收待做; 此实现不得标为来源完全对齐.
