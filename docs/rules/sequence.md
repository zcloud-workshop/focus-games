# 序列记忆

来源: A11 /sequence-memory/; T02 /sequence-memory; C09 /zh/games/sequence-memory-test; C12 /zh/games/frog-memory-leap.

来源 C 源码观察, 非运行验收: https://github.com/loethen/freefocusgames/tree/88336ed4e2f101998c2cb53794593a934390db9d. C09 从 3 步挑战, 练习起始 1-20; 每关生成新序列且相邻位置不重复, 准备 2 秒、亮 800ms、间隔 200ms, 正倒序分别计最长完成长度. 本站分别提供挑战和不计分练习, 采用上述核心规则.

C12 源码观察: 初关 4 个位置和 2 次跳跃, 每两关增加一个位置至 10, 每关增加一次跳跃至 9; 首个位置是起点而非需点击的落点, 相邻落点不重复. 成功得 100 + 关卡×20 分, 5 秒内另加 50、10 秒内另加 25, 错误可重试本关. 本站采用这些规则及原创位置和移动标记, 以距离决定跳跃持续时间; 位置分布、视觉、切换时序及失败后自动保存仍与参考不同. 本站失败后由用户选择重试或结束并保存.

A11、T02 方格/按钮预设数值和解锁尚未完整运行核验; C09、C12 的成功、错误、结束及重开仍需分别运行核验. 观察阶段不接受输入, 显示与隐藏记录帧时间和试次, 清理后不继续回调.
